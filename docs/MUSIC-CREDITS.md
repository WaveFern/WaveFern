# Music sample credits

The beat engine (67-beats.js, and the dev copy dev/dev-music-v1.js) makes most sounds in code. The dev music update adds recorded
instruments (`audio/inst`) and drum kits (`audio/kits`). Every file is royalty free. Files were trimmed, made mono, faded and peak
normalised, then encoded as MP3. Nothing else was changed.
