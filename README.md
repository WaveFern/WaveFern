# WaveFern Studios – Music Career Sim (split version)

Open `index.html` in a browser (needs internet for Three.js and the font).

- `css/style.css` – all styles
- `js/01…27-*.js` – the game code, split by section and loaded in order (keep the order in `index.html`)
- `assets/` – the two music tracks and the wallpaper, taken out of the old single file
- `js/27-boot.js` – starts the game

Edit the newest features in `js/25-v21.js` and `js/26-v24-upstairs-redesign.js`.

- `docs/THEMES.md` – theme sheet: colours, fonts, buttons, bubbles and shared classes for every app. Read it before changing any app UI.
